## Як працюємо з кодом

1. Кожен працює у своїй гілці: `git checkout -b nastia/compare-table`.
2. Коміти малі й часті, пуш щогодини.
3. Pull request у `main`; зливає автор, якщо збірка зелена. `main` завжди збирається.
4. Після кожного злиття в `main` сайт сам оновлюється на GitHub Pages.
5. Дані для інтерфейсу беремо з `data/` (спершу з `data/mock/`, далі зі справжніх файлів, формат той самий).
